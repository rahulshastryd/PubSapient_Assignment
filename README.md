Pharmacy Inventory Management System

Overview
This project is a Pharmacy Inventory Management System built as part of a technical assessment.
It allows users to manage medicines, track stock, record sales, and visually identify critical inventory conditions.

The application is implemented using a modern Angular frontend and a .NET Web API backend, following clean separation of concerns and domain-driven design principles.
